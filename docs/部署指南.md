### 阿里云 PostgreSQL 配置 (CentOS)

#### 1. 安装 PostgreSQL 15

```bash
# SSH 登录服务器
ssh root@47.92.96.143

# 安装官方仓库
yum install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# 安装 PostgreSQL 15
yum install -y postgresql15-server postgresql15

# 初始化数据库
/usr/pgsql-15/bin/postgresql-15-setup initdb

# 启动并设置开机启动
systemctl start postgresql-15
systemctl enable postgresql-15
```

#### 2. 配置远程访问

```bash
# 编辑 postgresql.conf
vi /var/lib/pgsql/15/data/postgresql.conf
# 修改: listen_addresses = '*'

# 编辑 pg_hba.conf
vi /var/lib/pgsql/15/data/pg_hba.conf
# 添加: host all all 0.0.0.0/0 md5

# 重启 PostgreSQL
systemctl restart postgresql-15
```

#### 3. 创建数据库和用户

```bash
sudo -u postgres psql

CREATE DATABASE vocab_assistant;
CREATE USER vocab_user WITH ENCRYPTED PASSWORD 'YourSecurePassword123';
GRANT ALL PRIVILEGES ON DATABASE vocab_assistant TO vocab_user;
\c vocab_assistant
GRANT ALL ON SCHEMA public TO vocab_user;
\q
```

#### 4. 阿里云安全组配置

在阿里云控制台 → 安全组 → 添加入站规则：
- 端口: 5432
- 来源: 0.0.0.0/0 (或指定 Vercel IP 段)

### Vercel 环境变量配置

在 Vercel 项目设置中添加：

```
DATABASE_URL=postgresql://vocab_user:YourSecurePassword123@47.92.96.143:5432/vocab_assistant
BLOB_READ_WRITE_TOKEN=vercel_blob_xxxxx
```

## 常用命令

```bash
# PostgreSQL 服务管理
systemctl status postgresql-15
systemctl restart postgresql-15

# 数据库连接测试
psql -h 47.92.96.143 -U vocab_user -d vocab_assistant

# 数据库备份
pg_dump -h 47.92.96.143 -U vocab_user vocab_assistant > backup.sql

# 数据库恢复
psql -h 47.92.96.143 -U vocab_user vocab_assistant < backup.sql
```
