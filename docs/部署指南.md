## 阿里云部署（生产环境）

### 服务器配置建议

| 规模 | CPU | 内存 | 月成本 |
|------|-----|------|--------|
| 小规模（<1万用户） | 4核 | 8GB | ¥660-760 |
| 标准（1-5万用户） | 8核 | 16GB | ¥1300-1500 |
| 大规模（5万+用户） | 16核 | 32GB | ¥3600-4200 |

### 部署步骤

1. **服务器准备**
```bash
# 安装 Node.js 20+
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 PM2、Nginx、PostgreSQL
sudo npm install -g pm2
sudo apt install -y nginx postgresql postgresql-contrib
```

2. **数据库配置**
```bash
sudo -u postgres psql
CREATE DATABASE word_app;
CREATE USER word_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE word_app TO word_user;
\q
```

3. **部署应用**
```bash
cd /var/www/word-app/web-admin
npm install
npx prisma generate
npx prisma db push
npm run build
pm2 start npm --name "word-app" -- start
pm2 startup && pm2 save
```

4. **执行部署脚本**
```bash
bash deploy-production.sh
```

## 常用命令

```bash
# 查看应用状态
pm2 status

# 查看日志
pm2 logs word-app

# 重启应用
pm2 restart word-app

# 数据库备份
pg_dump -U word_user word_app > backup.sql
```
