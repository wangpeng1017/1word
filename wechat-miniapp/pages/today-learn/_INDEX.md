# today-learn 今日学习模块

独立的新词学习入口，展示今日需学习的新单词数量。

## 文件清单

| 文件名 | 功能 |
|--------|------|
| today-learn.js | 页面逻辑：加载每日新词任务、欢迎动画逻辑 |
| today-learn.wxml | 页面结构：欢迎动画 overlay、新词任务卡片 |
| today-learn.wxss | 页面样式：卡片设计、动画样式 |
| today-learn.json | 页面配置 |

## UI 设计

### 欢迎动画
- 首次登录显示欢迎页面 (从 index 移入)
- 吉祥物与问候语
- "开始今日学习" 按钮

### 任务卡片
- 展示今日新词数量
- 预计耗时
- 学习按钮 / 完成状态
