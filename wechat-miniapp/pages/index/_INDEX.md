# index 首页模块

小程序首页，展示学习路径时间线和欢迎动画。
采用多邻国风格设计，支持学习计划展示和快速进入学习。

⚠️ 文件夹变化时请更新此文件

## 文件清单

| 文件名 | 功能 |
|--------|------|
| index.js | 首页逻辑：加载学习计划、处理天数点击 |
| index.wxml | 首页结构：学习路径时间线 |
| index.wxss | 首页样式：多邻国风格设计 |
| index.json | 首页配置 |

## UI 设计

### 学习路径
- 圆形节点左右交替排列
- 状态：已完成(绿) / 当前(橙) / 错过(红) / 锁定(灰)
- 显示日期(年月日)和单词数量
