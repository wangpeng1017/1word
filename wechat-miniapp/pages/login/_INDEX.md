# login 登录页模块

小程序登录页，支持手机号密码登录，集成协议勾选和客服入口。

⚠️ 文件夹变化时请更新此文件

## 文件清单

| 文件名 | 功能 |
|--------|------|
| login.js | 登录逻辑：表单验证、API调用、协议跳转、客服二维码 |
| login.wxml | 登录界面：表单输入、协议勾选、客服按钮 |
| login.wxss | 登录样式：响应式布局、协议文字换行 |
| login.json | 登录配置 |

## 核心功能

### 登录验证
- 手机号格式验证（11位）
- 密码输入验证
- 协议勾选验证（必须同意才能登录）

### 协议跳转
- 点击《隐私政策》跳转到 pages/privacy/privacy
- 点击《用户服务协议》跳转到 pages/agreement/agreement

### 客服功能
- 显示客服二维码弹窗
- 保存二维码到相册（需相册权限）
- 预览二维码大图
