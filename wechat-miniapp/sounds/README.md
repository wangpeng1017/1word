# 音效文件说明

请将以下音效文件放入此目录：

| 文件名 | 用途 | 推荐时长 |
|--------|------|----------|
| `correct.mp3` | 答对音效（清脆叮声） | 0.3-0.5秒 |
| `wrong.mp3` | 答错音效（低沉噗声） | 0.3-0.5秒 |
| `streak_5.mp3` | 连对5题里程碑 | 0.5-1秒 |
| `streak_10.mp3` | 连对10题里程碑 | 0.5-1秒 |
| `complete.mp3` | 完成学习庆祝声 | 1-2秒 |

## 推荐音效资源

- [Mixkit](https://mixkit.co/free-sound-effects/game/) - 免费游戏音效
- [Freesound](https://freesound.org/) - 开源音效库
- [Pixabay](https://pixabay.com/sound-effects/) - 免费音效

## 搜索关键词

- 答对: `correct`, `success`, `ding`, `positive beep`
- 答错: `wrong`, `error`, `fail`, `negative beep`
- 里程碑: `achievement`, `level up`, `fanfare`
- 完成: `celebration`, `victory`, `win`

## 注意事项

1. 文件格式必须为 MP3
2. 单个文件大小建议 < 50KB
3. 音量适中，避免过于刺耳
