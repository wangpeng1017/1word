  # CLAUDE.md - AI 编程助手规则

  ## 基础设置
  - 使用简体中文回复
  - Windows 优先用 Write 工具（避免 Edit 冲突）

  ## 📐 统一分形架构

  代码与文档镜像映射，每个模块同时拥有代码 + 文档：

  项目/
  ├── src/                    # 代码层
  │   ├── {module}/
  │   │   ├── _INDEX.md       # 代码索引
  │   │   └── *.ts
  │   └── _INDEX.md
  │
  ├── docs/                   # 文档层（与 src 镜像）
  │   ├── {module}/
  │   │   ├── _INDEX.md       # 文档索引
  │   │   ├── PRD.md          # 需求文档
  │   │   ├── TECH.md         # 技术文档
  │   │   └── DEPLOY.md       # 部署文档
  │   └── _INDEX.md
  │
  └── CHANGELOG.md            # 变更日志

  ---

  ## 🔄 变更同步规则

  | 变更类型 | 需更新的文档 |
  |----------|-------------|
  | 新增/修改/删除功能 | PRD.md + CHANGELOG |
  | API/数据结构变更 | TECH.md + CHANGELOG |
  | 环境/部署配置变更 | DEPLOY.md + CHANGELOG |
  | 新增/删除文件 | _INDEX.md |

  **每次代码变更后，AI 必须：**
  1. 识别变更类型
  2. 同步对应文档
  3. 记录到 CHANGELOG
  4. 输出同步报告

  🛠️ 特殊指令

  /xiaban - 下班检查

  检查并输出报告：
  1. 索引一致性 - _INDEX.md 与实际文件是否匹配
  2. PRD 同步 - 功能变更是否已记录
  3. TECH 同步 - API/数据结构是否已记录
  4. DEPLOY 完整性 - 部署文档是否完整
  5. CHANGELOG - 今日变更是否已记录

  输出格式：
  ## 下班检查报告
  | 检查项 | 状态 | 待修复 |
  |--------|------|--------|
  | 索引一致性 | ✅/⚠️ | {具体问题} |
  | PRD同步 | ✅/⚠️ | {具体问题} |
  | TECH同步 | ✅/⚠️ | {具体问题} |
  | DEPLOY | ✅/⚠️ | {具体问题} |
  | CHANGELOG | ✅/⚠️ | {具体问题} |

  /sync - 手动同步文档

  分析当前会话变更，补充遗漏的文档同步。

  📋 对话结束总结

  - 文档同步: ✅ PRD | ✅ TECH | ⚪ DEPLOY | ✅ CHANGELOG
