# 系统设置板块迭代开发计划

## 需求概述
1. **账号管理**：管理员可以新增账号，定义用户名和密码，权限和管理员一致
2. **操作日志**：记录管理后台所有账号的操作记录

## 现有基础分析

### 已有资源
- `operation_logs` 数据库表已存在（schema.prisma:365-382）
- `/api/logs` API 已实现（支持分页、筛选）
- `lib/log.ts` 日志记录工具已实现
- 登录时已记录操作日志

### 需要新增
- 账号管理 API 和前端页面
- 操作日志前端展示页面
- 侧边栏菜单调整

## 开发计划

### 第一部分：账号管理功能

#### 1.1 后端 API
**文件**: `/app/api/accounts/route.ts`

| 方法 | 功能 | 说明 |
|------|------|------|
| GET | 获取管理员账号列表 | 只返回 role=TEACHER 的用户 |
| POST | 创建新管理员账号 | 创建 user + teachers 记录 |

**文件**: `/app/api/accounts/[id]/route.ts`

| 方法 | 功能 | 说明 |
|------|------|------|
| GET | 获取单个账号详情 | - |
| PUT | 更新账号信息 | 支持修改名称、密码、状态 |
| DELETE | 删除账号 | 软删除（设置 is_active=false）或硬删除 |

#### 1.2 前端页面
**文件**: `/app/admin/settings/accounts/page.tsx`

功能：
- 账号列表展示（表格）
- 新增账号弹窗（用户名、邮箱、密码）
- 编辑账号弹窗
- 删除账号确认
- 重置密码功能
- 启用/禁用账号

## 技术要点

### 安全考虑
- 账号管理仅限 TEACHER/ADMIN 角色访问
- 密码使用 bcrypt 加密存储
- 不能删除自己的账号
- 不能禁用自己的账号

### 日志记录范围
- 登录/退出
- 账号：新增、修改、删除、重置密码、启用/禁用
- 学生：新增、修改、删除、批量导入
- 班级：新增、修改、删除
- 词汇：新增、修改、删除、批量导入
- 设置：修改系统设置
