# 管理员密码重置方案

当管理员忘记密码时，有以下几种方式可以重置密码：

## 方案一：使用脚本重置（推荐）

这是最简单的方式，适合有服务器访问权限的情况。

### 1. 列出所有管理员账号

```bash
cd web-admin
node scripts/reset-admin-password.js --list
```

### 2. 重置指定账号的密码

```bash
# 使用邮箱
node scripts/reset-admin-password.js admin@example.com 新密码

# 使用手机号
node scripts/reset-admin-password.js 13800138000 新密码
```

### 示例

```bash
node scripts/reset-admin-password.js admin@school.com 123456
```

---

## 方案二：通过数据库直接重置

如果无法运行脚本，可以直接在数据库中重置密码。

### 1. 生成加密密码

密码使用 bcrypt 加密，需要先生成加密后的密码。

**方法 A：使用在线工具**
- 访问 https://bcrypt-generator.com/
- 输入新密码，选择 rounds = 10
- 复制生成的 hash 值

**方法 B：使用 Node.js**
```javascript
const bcrypt = require('bcryptjs')
const hash = bcrypt.hashSync('你的新密码', 10)
console.log(hash)
```

### 2. 执行 SQL 更新

```sql
-- 查看所有教师/管理员账号
SELECT id, name, email, phone, role
FROM users
WHERE role = 'TEACHER';

-- 通过邮箱重置密码
UPDATE users
SET password = '加密后的密码hash', updated_at = NOW()
WHERE email = 'admin@example.com';

-- 通过手机号重置密码
UPDATE users
SET password = '加密后的密码hash', updated_at = NOW()
WHERE phone = '13800138000';
```

### 完整示例

```sql
-- 将 admin@school.com 的密码重置为 123456
UPDATE users
SET password = '$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy',
    updated_at = NOW()
WHERE email = 'admin@school.com';
```

## 方案三：创建新管理员账号

如果原账号无法恢复，可以创建一个新的管理员账号。

### 使用脚本创建

```bash
node scripts/create-admin.js
```

### 使用 SQL 创建

```sql
-- 1. 创建用户
INSERT INTO users (id, email, phone, password, name, role, is_active, created_at, updated_at)
VALUES (
  'user_' || extract(epoch from now())::text,
  'newadmin@example.com',
  '13900139000',
  '$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy', -- 密码: 123456
  '新管理员',
  'TEACHER',
  true,
  NOW(),
  NOW()
);

-- 2. 创建教师记录
INSERT INTO teachers (id, user_id, school, subject, created_at, updated_at)
VALUES (
  'teacher_' || extract(epoch from now())::text,
  (SELECT id FROM users WHERE email = 'newadmin@example.com'),
  '学校名称',
  '英语',
  NOW(),
  NOW()
);
```

## 安全建议

1. **定期更换密码**：建议每 3 个月更换一次密码
2. **使用强密码**：密码应包含字母、数字，长度至少 8 位
3. **记录密码**：将密码保存在安全的地方（如密码管理器）
4. **限制访问**：数据库和服务器访问权限应严格控制

## 常见问题

### Q: 重置密码后还是无法登录？

A: 请检查：
1. 密码是否正确输入（注意大小写）
2. 账号是否被禁用（is_active = false）
3. 清除浏览器缓存后重试

### Q: 如何查看账号是否被禁用？

```sql
SELECT id, name, email, is_active FROM users WHERE email = 'xxx@example.com';
```

如果 is_active = false，执行：
```sql
UPDATE users SET is_active = true WHERE email = 'xxx@example.com';
```
