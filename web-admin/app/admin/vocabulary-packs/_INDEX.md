# vocabulary-packs 词汇包管理

> 词汇包列表页和每日单词配置页面

⚠️ 文件夹变化时请更新此文件

## 文件清单

| 文件 | 功能 |
|------|------|
| page.tsx | 词汇包列表：新建、编辑、删除、启用/禁用 |
| [id]/page.tsx | 每日单词配置：Transfer穿梭框 + 批量粘贴添加 |

## 功能说明

### 列表页 (page.tsx)
- 创建词汇包（设置名称、描述、天数）
- 编辑/删除词汇包
- 启用/禁用词汇包
- 查看词汇包使用统计
- 跳转到每日单词配置

### 配置页 ([id]/page.tsx)
- 查看词汇包概览（总天数、总词数、平均每天）
- 每日单词列表预览
- 配置每天的单词列表：
  - Transfer穿梭框手动选择
  - 批量粘贴添加（支持多种分隔符）
  - 自动过滤已被其他天使用的单词
  - 搜索过滤（支持搜索单词和释义）

## API 依赖

| API | 方法 | 说明 |
|-----|------|------|
| /api/vocabulary-packs | GET/POST/PUT/DELETE | 词汇包CRUD |
| /api/vocabulary-packs/[id]/days | PUT | 更新每日单词配置 |
| /api/vocabularies | GET | 获取所有可选词汇 |
