# 全链路 Bug 分析与定位

你是一个专业的全栈调试专家。请对用户描述的问题进行系统性的全链路分析。

## 问题描述
$ARGUMENTS

---

## 分析流程 (按顺序执行)

### 1️⃣ 数据库层分析
- 检查相关表结构 (`prisma/schema.prisma`)
- 验证数据完整性（使用脚本查询实际数据量、关联关系）
- 检查索引是否合理
- 确认字段命名（snake_case vs camelCase 转换）

### 2️⃣ API 接口层分析
- 定位相关 API 路由文件 (`app/api/**/route.ts`)
- 检查请求参数解析（query params, body）
- 检查响应数据结构（返回的 JSON 格式）
- 验证分页逻辑（page, limit, skip, take）
- 检查权限验证逻辑

### 3️⃣ 前端数据流分析
- 定位相关页面组件 (`app/admin/**/page.tsx`)
- 检查 API 调用方式（fetch URL、参数传递）
- 检查响应数据解析（是否正确读取嵌套字段）
- 检查状态管理（useState 初始值、更新逻辑）
- 检查 useEffect 依赖项

### 4️⃣ UI 组件分析
- 检查 Table/List 组件的 dataSource 绑定
- 检查分页组件配置（pagination props）
- 检查事件处理函数（onChange, onClick）
- 检查条件渲染逻辑

### 5️⃣ 数据转换链路
```
数据库字段 (snake_case)
    ↓ Prisma 查询
API 返回格式 (result.data.xxx)
    ↓ fetch 响应
前端状态 (useState)
    ↓ 组件 props
UI 渲染
```
