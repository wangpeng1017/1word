# 词汇库配置交互优化

## 目标
优化"词汇库-配置词汇"功能的交互体验，将下拉多选改为搜索添加 + 表格管理模式。

## 当前问题
- 使用 Select mode="multiple" 下拉多选
- 词汇量可达上万个，渲染性能差
- 下拉选择大量数据时体验极差

## 设计方案：搜索添加 + 表格管理

### 交互流程
1. 用户在搜索框输入词汇关键词
2. AutoComplete 显示匹配结果（限制 50 条）
3. 点击"添加"将词汇加入已选列表
4. Table 展示已选词汇，支持删除操作

## 影响范围

### 需要修改的文件
| 文件 | 修改内容 |
|------|----------|

## 实施步骤

### 步骤 1: 修改状态管理
- 将 `selectedVocabIds: string[]` 改为 `selectedVocabs: Vocabulary[]`
- 添加 `searchValue` 和 `searchResults` 状态

### 步骤 2: 实现搜索逻辑
- 添加防抖搜索函数（300ms）
- 搜索结果限制 50 条
- 排除已被其他天使用的词汇

### 步骤 3: 替换 Modal 内容
- 移除 Select 组件
- 添加 AutoComplete 搜索组件
- 添加 Table 展示已选词汇

### 步骤 4: 调整保存逻辑
- 从 `selectedVocabs` 提取 ID 数组提交

## 验收标准
- [ ] 搜索输入后显示匹配词汇（最多 50 条）

- [ ] 已选词汇以表格形式展示
- [ ] 支持删除已选词汇
- [ ] 支持清空已选词汇
- [ ] 保存功能正常
